This is a placeholder post, mostly so I can see how the notes section renders. Here's what I actually expect to write about.

**Agentic evaluation.** Most of my time goes into measuring whether an agent did the thing it was asked to do. That turns out to be much harder than measuring whether a model produced fluent text. Task completion, instruction following, and response quality pull in different directions, and a benchmark that collapses them into one number hides exactly the failures you need to see. I want to write about how those benchmarks get designed and where they mislead you.

**Inference serving tradeoffs.** Batching, KV cache behavior, quantization, and where the pre- and post-processing actually belongs. The decisions that look like implementation detail in a research notebook become the whole latency budget in production.

**Lessons from shipping fine-tuned models.** LoRA and RLHF are the easy part. What's harder is reproducibility across experiments, keeping evaluation honest as the model changes underneath you, and the gap between an offline win and a user noticing a difference.

Roughly, the theme is the loop between model behavior and production outcomes — the part that's hard to see from either end alone.
